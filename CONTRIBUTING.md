# Contributing to Printable Visualize Sound

Thank you for your interest in contributing!

## Getting Started

1. Fork this repository
2. Clone your fork: `git clone https://github.com/YOUR_USERNAME/printable-visualize-sound.git`
3. Create a branch: `git checkout -b fix/your-fix-name`
4. Make your changes
5. Commit: `git commit -m "brief description"`
6. Push: `git push origin fix/your-fix-name`
7. Open a Pull Request

## Project Structure

| Folder | Purpose |
|--------|---------|
| `vsound/` | Core Python audio processing & visualization |
| `scripts/` | Utility scripts and entry points |
| `web/` | Web-based UI for previewing visualizations |
| `paper/` | Research paper (Markdown) |

## Guidelines

- Keep changes focused — one fix per PR
- Add comments for non-obvious code
- Test your changes before submitting

## Metrics Used

- **SNR** — Signal-to-Noise Ratio
- **STOI** — Short-Time Objective Intelligibility
- **PESQ** — Perceptual Evaluation of Speech Quality
